# Rendered UI/UX review
Date: 16 October 2026. Source baseline plus public browser inspection and local production-mode preview.

## Observed BM experience
Public homepage at https://www.bmcontractorstz.com/ was inspected in the in-app browser. The initial narrow screenshot showed the help popup covering most of the hero; the header brand was truncated beside the language controls. The page uses a predominantly dark/red visual system, decorative live-camera labels and repeated visual effects. These do not match the newly supplied blue identity as well as a quieter corporate design could.

The accessibility tree confirmed package slugs in product links, missing product headings, generic review styling, inconsistent WhatsApp label/destination and project-detail links without corresponding routes. Phase 1A repairs product mapping, review/trust text, project links and the approved WhatsApp mapping, without a complete redesign.

Local preview inspection confirmed EN/SW language links, Swahili content and clear product-translation notices. Native screenshot inspection at mobile size exposed the popup obstruction; the full redesign is deferred for review. Tablet/desktop concepts are described in 19; do not treat unperformed breakpoint checks as certified.

## Phase 1B priorities
- Replace text BM placeholder with official shield/wordmark treatment.
- Use the supplied blue identity, restrained navy/text neutrals, readable contrast and more whitespace.
- Keep CCTV/fence/gates as first-line services; add verified engineering/power/procurement alongside them.
- Prefer a user-invoked help action over a timed overlay obscuring mobile content.
- Use real, consented installation photos; remove faux live feeds and unsupported credentials.
- Review remaining mixed-language labels and natural Tanzanian Kiswahili with the owner.
- Retain touch targets, keyboard focus, clear form labels/errors and reduced-motion support.

No customer data, live forms or OTP/SMS were submitted during public inspection. Screenshots are visual observations, not a Lighthouse or accessibility certification.
